# Support

Agent Control Plane is maintained by one person. This page says what that means in practice.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/agent-control-plane/issues/new/choose).
  Use the bug report or feature request form so the maintainer has what is needed to act.
- **Response time:** best-effort, with no SLA. Nobody is on call, and a reply can take a while.
- **Security reports:** do not open a public issue. Follow [`SECURITY.md`](SECURITY.md), which uses
  GitHub private vulnerability reporting.
- **Versioning:** ACP follows Semantic Versioning for its policy and normalized contracts, as described in [`docs/VERSIONING.md`](docs/VERSIONING.md). The package version is in `pyproject.toml`.
