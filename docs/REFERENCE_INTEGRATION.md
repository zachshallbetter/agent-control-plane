# Reference integration

InfiniteVerse is the first reference integration for ACP. Its integration supplies:

- GitHub Projects and issue packet fixtures;
- local Git/worktree execution;
- Railway deployment and health evidence;
- Vercel browser evidence;
- versioned corpus freshness checks;
- coordinator bridge and webhook delivery behavior.

These are adapter fixtures and acceptance examples. ACP does not own InfiniteVerse product schemas, service contracts, publication models, or domain terminology.
